Software Engineer Test
This test is for building API services with microservice architecture.
Instructions:
1) Please develop the API according to the spec requirement.
2) Please code in ONLY the following languages : Java and Spring
   framework using Spring cloud and Spring Boot
3) You can show the results of your application on a public server
   or make a demo documentation in a pdf format
4) Please use Git for version control
5) Readme of your project should include:
   a) Overview of tech stack (language, framework, library, etc)
   b) Brief description of why this tech stack was chosen
   c) Setup instructions (build & run) on linux / windows
   d) Share your project on git and set public access
   Study Case
- Create Java Microservices with Spring Cloud and Spring Boot
1. Build a Discovery Service with Spring Eureka
2. Build a Gateway Service with Spring Cloud Gateway
3. Build a Configuration service with Spring Cloud Config
4. Build a CRUD API service with Spring Data REST and
   Feign (minimal 2 repository)
5. Implement API Security with Spring Security OAuth is a plus
6. Implement API Documentation with swagger is a plus
7. Implement Unit testing is a plus
